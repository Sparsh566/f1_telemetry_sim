# 📦 Models Directory

This directory stores serialized model artifacts and metadata generated by the **Formula 1 Telemetry Simulator & Predictive Analytics Platform**.

---

## 🛡️ Critical Security Notice

> **WARNING**: Python `pickle` and `joblib` artifacts use object serialization that can execute arbitrary Python bytecode during deserialization (`joblib.load()` or `pickle.load()`).
> **Never load untrusted model files downloaded from unknown third parties.**

---

## Supported Formats

1. **Joblib (`.joblib`)**:
   - Primary format for Scikit-Learn pipelines (`RandomForestRegressor` + `ColumnTransformer`).
   - Supports **zero-copy memory mapping (`memmap`)** for large NumPy weight arrays on disk.
   - Recommended for high-throughput pit wall inference.

2. **Pickle (`.pkl`)**:
   - Python standard library object serialization.
   - Used for raw parameter bundles of the pure NumPy Multi-Layer Perceptron and Single Perceptron weights and biases.

---

## Metadata Schema

Every saved bundle contains:
- `format_version`: String version identifier (e.g. `"1.0"`).
- `python_version`: Python runtime version (e.g. `"3.14.6"`).
- `sklearn_version`: Scikit-Learn release version.
- `joblib_version`: Joblib version used for serialization.
- `feature_schema`: List of required feature columns in exact order.
- `target`: Target column name (`"lap_time"`).
- `metrics`: Evaluation results on held-out test races ($R^2$, MAE, RMSE, Baseline Mean MAE, Lift).
- `created_at_utc`: ISO UTC timestamp.
